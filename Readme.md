# PLAY FOR ALL - 게임 플레이 데이터 분석 프로젝트

## 1. 프로젝트 소개

**PLAY FOR ALL**은 게임 사용자의 플레이 기록을 분석하여 개인에게 적절한 게임 난이도를 제공하는 프로젝트입니다.

게임을 잘하는 사람뿐만 아니라 게임이 익숙하지 않은 사람도 쉽게 즐길 수 있도록 만드는 것을 목표로 했습니다.

사용자가 도형 규칙을 맞히는 게임을 진행하면 정답률, 응답 시간, 힌트 사용 횟수 등의 데이터가 기록됩니다. 이후 이 데이터를 분석하여 사용자의 게임 수행 결과를 확인할 수 있도록 구현했습니다.

Python과 Streamlit을 활용했으며, 웹사이트에서 직접 게임을 실행하고 분석 결과를 확인할 수 있습니다.

- **프로젝트명:** PLAY FOR ALL
- **주제:** 게임 플레이 데이터 분석을 통한 개인 맞춤형 난이도 추천
- **개발 환경:** Python, Streamlit, HTML, CSS, JavaScript
- **프로젝트 인원:** 3명

### 프로젝트 링크

- GitHub: https://github.com/DOREMICDEF/Bigdata_project
- Streamlit: https://play-for-all-doremicdef.streamlit.app/

## 2. 주제 선정 이유

평소 게임을 즐기면서 같은 게임이라도 사람마다 느끼는 난이도가 다르다는 점에 관심을 가지게 되었습니다.

게임을 많이 해본 사람에게는 쉬운 문제도 처음 접하는 사람에게는 어렵게 느껴질 수 있습니다. 특히 고령층이나 디지털 기기 사용이 익숙하지 않은 사람들은 게임의 조작이나 진행 방식 자체를 어려워할 수 있다고 생각했습니다.

그래서 모든 사용자에게 동일한 난이도를 제공하기보다는, 실제 게임 플레이 데이터를 분석하여 사용자에게 맞는 난이도를 추천하는 서비스를 만들어 보고자 했습니다.

또한 수업에서 배운 데이터 수집, 처리, 분석, 시각화 과정을 직접 구현해 볼 수 있다는 점에서 이 주제를 선택했습니다.

## 3. 주요 기능

### 3.1 도형 규칙 게임

일정한 규칙으로 나열된 도형을 보고 다음에 나올 도형을 맞히는 게임입니다.

게임은 연습 문제 1개와 본 게임 6문제로 구성되어 있으며, 난이도에 따라 도형 규칙과 제한 시간이 달라집니다.

| 난이도 | 문제 유형 | 제한 시간 |
|---|---|---|
| 1단계 | AB 반복 규칙 | 40초 |
| 2단계 | ABC 반복 규칙 | 35초 |
| 3단계 | AAB / ABB 반복 규칙 | 30초 |

사용자는 게임을 시작하기 전에 자신의 게임 경험을 선택할 수 있으며, 이에 따라 초기 난이도가 설정됩니다.

### 3.2 사용자 편의 기능

게임이 익숙하지 않은 사용자도 쉽게 플레이할 수 있도록 몇 가지 기능을 추가했습니다.

- 글씨 크게 보기
- 문제 제한 시간 1.5배 늘리기
- 힌트 사용
- 게임 일시정지
- 연습 문제 진행
- 게임 기록 JSON 파일 다운로드

### 3.3 게임 데이터 분석

게임을 완료하면 플레이 기록을 JSON 파일로 저장할 수 있습니다.

저장된 파일을 Streamlit에 업로드하면 사용자의 게임 수행 결과를 분석하여 화면에 보여줍니다.

분석에 사용하는 주요 데이터는 다음과 같습니다.

| 데이터 | 내용 |
|---|---|
| 정답 여부 | 문제별 정답 및 오답 기록 |
| 응답 시간 | 각 문제를 해결하는 데 걸린 시간 |
| 힌트 사용 | 문제별 힌트 사용 여부 |
| 시간 초과 | 제한 시간을 초과한 횟수 |
| 게임 난이도 | 플레이한 문제의 난이도 |

## 4. 데이터 분석 내용

이번 프로젝트에서는 사용자의 게임 플레이 기록을 이용하여 정답률, 응답 시간, 힌트 사용 횟수 등을 분석했습니다.

### 4.1 정답률 분석

전체 문제 중 몇 문제를 맞혔는지 계산합니다.

`정답률 = (정답 수 / 전체 문제 수) × 100`

정답률을 통해 사용자가 현재 난이도에서 어느 정도 문제를 해결했는지 확인할 수 있습니다.

### 4.2 응답 시간 분석

각 문제를 해결하는 데 걸린 시간을 기록하고 평균 응답 시간과 중앙값을 계산합니다.

응답 시간이 긴 문제와 짧은 문제를 비교하여 사용자가 어떤 문제에서 어려움을 겪었는지 살펴볼 수 있습니다.

### 4.3 힌트 및 시간 초과 분석

문제를 해결하는 과정에서 힌트를 사용했는지, 제한 시간을 초과했는지 확인합니다.

단순히 정답률만 보는 것이 아니라 문제를 해결하는 과정도 함께 살펴보기 위해 해당 데이터를 활용했습니다.

### 4.4 데이터 시각화

분석 결과를 쉽게 확인할 수 있도록 Streamlit과 Plotly를 사용했습니다.

구현한 분석 화면에서는 다음 내용을 확인할 수 있습니다.

- 전체 정답률
- 정답 및 오답 개수
- 평균 응답 시간
- 중앙값 응답 시간
- 힌트 사용 횟수
- 시간 초과 횟수
- 문제별 응답 시간 그래프
- 문제별 상세 기록

특히 문제별 응답 시간을 선그래프로 나타내어 게임이 진행되는 동안 응답 시간이 어떻게 변했는지 확인할 수 있도록 했습니다.

### 4.5 난이도 추천

게임 수행 결과를 활용한 규칙 기반 난이도 추천 기능도 구현했습니다.

| 조건 | 추천 난이도 |
|---|---|
| 정답 3개 미만 또는 시간 초과 2회 이상 | 한 단계 낮춤 |
| 정답 5개 이상, 응답 시간 비율 중앙값 60% 이하, 힌트 1회 이하 | 한 단계 높임 |
| 그 외 | 현재 난이도 유지 |

현재는 정해진 조건에 따라 난이도를 추천하는 방식이며, 머신러닝을 이용한 AI 학습 모델은 아직 적용하지 않았습니다.

추천 기능 관련 코드는 `Bigdata_project-main/play_for_all/core.py`에 작성되어 있습니다.

이번 프로젝트에서 주로 사용한 데이터는 게임을 직접 플레이하면서 생성되는 기록입니다.

## 8. 실행 방법

### 8.1 Streamlit 웹사이트 이용

아래 주소에 접속하면 별도의 설치 없이 게임을 실행할 수 있습니다.

**https://play-for-all-doremicdef.streamlit.app/**

사용 방법은 다음과 같습니다.

1. 웹사이트에 접속합니다.
2. '게임하러 가기' 버튼을 클릭합니다.
3. 게임을 진행합니다.
4. 게임 완료 후 JSON 기록을 다운로드합니다.
5. 메인 화면으로 돌아와 JSON 파일을 업로드합니다.
6. 분석 페이지에서 결과를 확인합니다.

### 8.2 직접 실행

GitHub 저장소를 다운로드한 후 `STREAMLIT` 폴더에서 실행합니다.

필요한 라이브러리 설치:

```bash
pip install -r requirements.txt
```

Streamlit 실행:

```bash
streamlit run app.py
```

실행 후 브라우저에서 `http://localhost:8501`에 접속하면 됩니다.

## 13. 프로젝트 결과 및 느낀 점

이번 프로젝트를 진행하면서 데이터를 분석하기 위해서는 먼저 어떤 데이터를 수집할지 정하는 과정이 중요하다는 것을 알게 되었습니다.

처음에는 간단한 도형 게임을 구현하는 것에서 시작했지만, 게임 기록을 저장하고 Python으로 분석한 뒤 Streamlit에서 시각화하는 과정까지 경험할 수 있었습니다.

특히 정답률뿐만 아니라 응답 시간과 힌트 사용 여부 등을 함께 분석하면 사용자의 플레이 특성을 조금 더 자세히 살펴볼 수 있다는 점을 확인했습니다.

다만 현재는 한 라운드의 플레이 기록을 중심으로 분석하고 있어 사용자별 장기적인 변화까지 확인하기는 어렵습니다.

앞으로는 여러 라운드의 데이터를 축적하고, 머신러닝을 활용하여 사용자에게 적합한 난이도를 예측하는 기능까지 발전시키고 싶습니다.
