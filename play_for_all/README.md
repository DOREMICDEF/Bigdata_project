# PLAY FOR ALL

큰 도형 버튼으로 반복 규칙을 찾는 1라운드 게임과 Streamlit 분석 앱입니다. **게임 실행 → 수행 기록 → 다음 난이도 추천**까지 연결되어 있습니다. 2라운드 게임과 학습된 AI 모델은 아직 포함하지 않습니다.

## 가장 빨리 게임하기

`frontend/index.html`을 Chrome 또는 Edge에서 여세요. 인터넷과 설치 없이 실행됩니다.

1. 게임 경험을 선택하고 필요한 경우 큰 글씨·추가 시간을 켭니다.
2. 기록 이용에 동의한 뒤 연습 문제와 본 게임 6문항을 풉니다. 동의 없이 기록 없는 연습만 이용할 수도 있습니다.
3. 결과 화면에서 **내 기록 받기 · JSON**을 눌러 보관합니다.
4. Streamlit의 **기록 분석**에서 JSON을 불러옵니다. Streamlit 안에서 게임을 하면 자동 전달됩니다.

## Streamlit 실행

Python 3.11~3.13과 인터넷 연결이 필요한 최초 설치 과정입니다. 권장 버전은 검증에 사용한 Python 3.12입니다.

Windows PowerShell에서 이 폴더를 연 다음 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 http://127.0.0.1:8501 을 엽니다. 종료는 터미널에서 Ctrl+C입니다.
다음 실행부터는 마지막 명령만 실행하면 됩니다. `run_windows.cmd`를 실행해도 됩니다. 이 파일은 의존성을 설치하지 않으며 먼저 만든 `.venv`를 사용합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `frontend/index.html` | 설치 없는 게임 및 Streamlit 양방향 컴포넌트 |
| `app.py` | 게임 표시, JSON 가져오기, 지표·차트·추천 근거, CSV 내려받기 |
| `core.py` | 데이터 검사, 정답 재계산, 지표 집계, 규칙 기반 추천 |
| `tests/test_core.py` | 추천 및 기록 검증 테스트 |
| `requirements.txt` | 실행 의존성 |
| `DATA_DICTIONARY.md` | 기록 필드, 단위, 개인정보 처리 및 AI 확장 기준 |
| `TEST_REPORT.md` | 실제 확인한 기능과 미검증 범위 |

## 게임과 추천 기준

- 1라운드는 연습 1문항 + 평가 6문항입니다. 연습은 저장·평가하지 않습니다.
- 게임 경험이 처음·미응답이면 기초, 가끔이면 보통, 자주면 도전으로 시작합니다. 이 대응은 개발 가설이며 공개 통계에서 학습한 결과가 아닙니다.
- 기초는 AB 반복과 문항당 40초, 보통은 ABC 반복과 35초, 도전은 AAB/ABB 반복과 30초입니다. 문제의 도형·배열 길이·선택지 위치는 무작위이며 같은 문제가 다시 나올 수 있습니다. 표준화된 검사 문항이 아닙니다.
- 추가 시간은 제한 시간을 1.5배로 늘립니다. 지원 사용 자체에는 감점이 없습니다.
- 4문항 이상 정답이면 라운드 목표 달성입니다. 6문항을 모두 마친 ‘완료’와 ‘목표 달성’을 구분합니다.
- 정답 3개 미만 또는 시간 초과 2회 이상이면 한 단계 하향 추천합니다.
- 그 외 정답 5개 이상 + 중앙 응답 시간 비율 60% 이하 + 힌트 1회 이하면 한 단계 상향 추천합니다. 나머지는 유지합니다.
- 추천 범위는 1~3이며 경계에서는 그대로 유지합니다. 응답 시간 비율은 지원 적용 후 제한 시간을 기준으로 계산합니다.
- 실패는 플레이 화면에 안내하지만 난이도 하향 알림은 표시하지 않습니다. 다음 난이도와 근거는 분석 화면에서 확인합니다.
- 숨겨진 브라우저 탭과 수동 일시정지는 시간 측정을 멈춥니다. 다시 이어서 하기를 눌러 재개합니다. Streamlit 내부의 분석 탭으로 이동하는 것은 브라우저 탭 숨김과 다르므로 진행 중에는 먼저 ‘잠깐 쉬기’를 누르세요.

## 데이터 처리

이름·연락처를 수집하지 않습니다. 연령대·장애 여부는 별도 선택 동의 후에만 입력하며 현재 난이도 결정에는 쓰지 않습니다. 장애 여부를 입력하지 않아도 접근성 기능을 이용할 수 있습니다.

단독 게임은 브라우저 메모리에서 실행하며 쿠키·localStorage에 플레이 기록을 저장하지 않습니다. Streamlit 게임은 완료 기록을 로컬 서버의 해당 세션 메모리로 전송합니다. 앱이 기록을 파일·DB에 자동 저장하지는 않습니다. 직접 내려받은 JSON/CSV는 사용자가 삭제해야 합니다. 세션 초기화 버튼은 서버 세션과 게임 화면을 초기화하지만 이미 받은 파일까지 삭제하지 않습니다. 실참여자 자료는 저장소에 커밋하지 마세요.

참여자 ID는 현재 게임 페이지 안에서 재도전 시 유지됩니다. 새 참여자로 시작하거나 페이지를 새로 열면 새 ID가 생기므로 여러 날의 동일인 추적에는 별도 동의와 안정적인 가명 관리가 필요합니다. 부분 진행 기록과 중도 이탈은 현재 내보내지 않습니다. 완료된 파일만으로 전체 참여자의 중도 이탈률이나 재도전율을 계산하면 안 됩니다.

## 공개 데이터와 AI의 현재 상태

[NIA 2025 디지털정보격차 실태조사](https://nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=29168&cbIdx=81623)는 활용 후보입니다. 출처 페이지와 보고서 구성을 확인했으며 통계 수치 추출·적재·모델 학습은 하지 않았습니다. 집단 지표를 개인 게임 실력으로 간주하지 않습니다.

현재 결과는 `rule_baseline_v1` 규칙 기반 추천입니다. 의사결정나무 등 학습 모델은 **현재 라운드 특징 + 다음 적용 난이도 + 실제 다음 라운드 성공 여부**를 확보한 후 개발해야 합니다. 현재 앱은 다음 라운드 결과가 없으므로 해당 모델을 학습하거나 예측 확률을 출력하지 않습니다.

## 검증과 시연

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

발표 시연 순서: 시작 화면에서 접근성 기능 설명 → 연습과 6문항 플레이 → 기록 분석에서 정답률과 시간 차트 설명 → 초기/추천 수준 비교 → 공개 데이터 및 학습 모델은 후속 단계임을 설명합니다. 시연 중 다른 이용자의 기록은 업로드하지 마세요.

보고서는 상위 폴더의 `PLAY_FOR_ALL_보고서.docx`입니다. 대회가 요구한 최종 제출 형식은 HWP/HWPX이므로, 제출 시 한글에서 문서를 열고 HWPX로 저장한 뒤 5쪽 이내인지 다시 확인해야 합니다. 참가자 정보·서명·동의서는 대신 작성하지 않았습니다.
