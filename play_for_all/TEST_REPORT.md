# 기능 검증 결과

검증일: 2026-11-10. 환경: Windows, Python 3.12, Streamlit 1.56.0, Chrome와 Playwright 자동 조작.

## 단위 테스트

`python -m unittest discover -s tests -v`: **14개 테스트 통과**.

| 영역 | 확인 내용 |
|---|---|
| 난이도 추천 | 상향·하향·유지, 최저·최고 수준의 경계 |
| 추천의 근거 | 시간 초과, 힌트 사용, 느린 응답에 따른 기준 적용 |
| 지원 및 선택 정보 | 추가 시간 사용 자체에 불이익 없음, 나이·장애 여부에 따른 추천 변화 없음 |
| 정답 검증 | 배열 길이가 달라져도 정답 계산, 브라우저의 허위 정답 필드를 재계산 |
| 데이터 검사 | 미동의·미완료·NaN·음수 시간·잘못된 패턴·제한 시간 불일치 등 거부 |
| 데이터 왕복 | JSON 내보내기/다시 읽기, 알 수 없는 개인정보 필드 제거, 건너뛰기 집계 |

## 브라우저에서 확인한 흐름

1. 기록 이용 동의 전 시작 버튼 비활성화.
2. 동의 없이 연습만 실행 후 시작 화면 복귀.
3. 추가 시간 적용과 일시정지·재개.
4. 힌트 사용, 정답, 오답, 건너뛰기와 시간 초과.
5. 6문항 완료 후 결과 표시와 실제 JSON 다운로드.
6. 재도전 시 1번 문항부터 다시 시작.
7. 가로 390px 모바일 화면에서 수평 넘침 없음.
8. Streamlit 안에서 게임 완료 시 기록 자동 전달.
9. 분석 화면의 지표, 차트와 문항 표 표시.
10. 독립 실행 게임의 JSON 가져오기 및 세션 기록 수 증가.
11. 현재 세션 초기화 후 빈 기록 상태 복귀.

시간 초과 검사는 브라우저 가상 시계를 진행시켜 수행했습니다. 자동화 입력으로 생성된 반응 시간과 정답률은 실제 이용자 성과를 의미하지 않습니다. 검증 기록은 배포용 프로젝트에 포함하지 않았습니다.

## 확인하지 않은 범위

- 실제 고령층·장애인·게임 초보자의 사용성 및 효과
- 스크린리더와 다양한 보조공학 기기 호환성
- 난이도 수준 간 실제 체감 난도와 규칙 임계값의 타당성
- 학습 모델의 성능 및 공정성
- 여러 기관의 동시 접속, 운영용 인증·영구 데이터 저장
- 다음 라운드 실행과 초기 대비 개선 효과
